# AI销售运营助手

一个帮助销售运营人员提升客户信息处理效率、辅助客户分层与跟进决策的轻量工具。

## 背景

投递京东销售运营实习生岗位时，研究了销售运营的日常工作场景——同时跟进几十个企业客户，手动做客户分层、写跟进方案、出汇总报表非常耗时。这个工具就是用AI自动完成这些重复性工作。

## 核心功能

| 功能 | 说明 |
|------|------|
| **客户数据分析** | 上传Excel/CSV，自动完成行业分布、规模分层和优先级评分 |
| **AI跟进建议** | 选择客户，AI自动分析采购行为，生成跟进话术和策略 |
| **销售看板** | 关键运营指标可视化：客户结构、跟进情况、采购趋势 |

## 技术架构

- **前端/后端**：Streamlit（轻量一体）
- **数据处理**：Pandas
- **AI**：OpenAI GPT-4o-mini / 规则引擎（无API key时自动降级）
- **图表**：Plotly
- **数据源**：CSV/Excel

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 `http://localhost:8501` 即可使用。

内置20条模拟企业客户数据，无需额外准备数据。

## 客户评分逻辑

A/B/C三级评分基于四个维度：
- 年采购额（40%）
- 合作时长（20%）
- 跟进频率（20%）
- 意向等级（20%）
